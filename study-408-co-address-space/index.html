408计组｜RAM、MAR、MDR与地址空间

先回忆，再核对；复习完后标记一次。

当前浏览器无法保存复习记录，阅读和自测仍可使用。

本篇整理本次学习中容易混淆的基础：RAM存什么，MAR和MDR存什么，以及怎样根据地址空间计算MAR位数。对应计组的计算机硬件组成、存储器容量和编址知识；学习3.3之前先把这些关系分清。

继续学习：计组3.3｜存储器扩展、片选与CPU连接。

一、RAM、MAR、MDR分别是什么

RAM是存储器；MAR和MDR是计组模型中CPU与主存交换信息所用的寄存器。

名称 英文全称 中文名称 保存什么 做题时关注什么
RAM Random Access Memory 随机存取存储器 程序和数据 容量、单元数、每单元位数
MAR Memory Address Register 存储器地址寄存器 本次要访问的存储单元地址 能表示多少个不同地址
MDR Memory Data Register 存储器数据寄存器 本次从主存读出或准备写入主存的数据 数据的位数

SRAM、DRAM都属于RAM。ROM是另一类存储器，通常在正常运行时提供只读的程序或常量。芯片类型与容量规格是两个维度：ROM、RAM都有多种规格，具体规格以题目为准。

例如，CPU要读取RAM中地址为2000H、内容为A5H的单元：

  1. MAR保存2000H，指出“访问哪里”。
  2. 地址经总线和译码电路选中RAM中的对应单元。
  3. 该单元输出A5H，读出的数据进入MDR。

向同一单元写入A5H时，MAR仍保存2000H，MDR则先保存准备写入的A5H。

记忆：RAM存程序和数据，MAR存访存地址，MDR存读写数据。地址值和数据值要分开。

二、容量、单元数与位宽

芯片规格通常写作“单元数×每单元位数”。若有\(M\)个单元，每单元\(w\)位，则：

\[ C=M\times w\ \text{bit}. \]

本篇按考研存储器题的常用约定，\(1\text{B}=8\text{bit}\)，\(1\text{K}=2^{10}\)，\(1\text{MB}=2^{20}\text{B}\)。

写法 单元数 每单元位数 总容量
\(8\text{K}\times8\)位 8K 8位 8KB
\(4\text{K}\times16\)位 4K 16位 8KB
\(4\text{K}\times8\)位 4K 8位 4KB
\(4\text{K}\times4\)位 4K 4位 2KB

所以：

\[ 8\text{KB}=8\text{K}\times8\text{bit} =4\text{K}\times16\text{bit} =64\text{Kbit}. \]

8KB只说明总容量；\(8\text{K}\times8\)位还说明了存储器的组织方式。 只知道容量，不能直接认定有多少个存储单元，也不能直接认定数据位宽。

三、MAR位数决定地址个数

MAR有\(n\)位，最多可表示\(2^n\)个不同地址。全部使用且从0连续编号时，地址编号范围是\(0\)至\(2^n-1\)。

\[ \text{最多地址个数}=2^n. \]

但“有多少个地址”还没有说明对应多少字节。还需要知道编址单位，即每个地址对应多大的一份存储空间。

设每个地址对应\(u\)字节，则：

\[ \text{最大地址空间容量}=2^n\times u\ \text{B}. \]

MAR位数 编址方式 每个地址对应 最大地址空间容量
16位 按字节编址 1B 64KB
16位 按16位字编址 2B 128KB
16位 按32位字编址 4B 256KB

三行都只有\(2^{16}\)个地址，只是每个地址代表的容量不同。

按字节编址时，一个32位字占4个字节地址；按32位字编址时，一个地址对应整个32位字。 数据位宽为32位，不代表一定按字编址。

四、反过来根据地址空间求MAR位数

做题先把地址空间容量换算成地址个数，再计算需要多少位来表示。

设从0开始的连续地址空间容量为\(C\)字节，编址单位为\(u\)字节，所需MAR最少位数为：

\[ n_{\min}=\left\lceil\log_2\frac{C}{u}\right\rceil. \]

例1：64MB地址空间，按字节编址

\[ \frac{64\text{MB}}{1\text{B}} =2^{26}\text{个地址} \quad\Rightarrow\quad \text{MAR至少26位}. \]

例2：同为64MB，按32位字编址

一个编址单位为\(32\text{bit}=4\text{B}\)，因此：

\[ \frac{64\text{MB}}{4\text{B}} =2^{24}\text{个地址} \quad\Rightarrow\quad \text{MAR至少24位}. \]

容量相同，编址单位不同，所需地址位数也不同。

五、地址空间与实际RAM容量

地址空间表示能对多少个位置编号；实际RAM容量表示安装了多少存储资源。

例如，MAR有16位，按字节编址：

  • 地址空间为64KB，地址编号为0000H～FFFFH。
  • 实际可以只安装16KB存储器，安排在0000H～3FFFH。
  • MAR仍然是16位，其余地址可以留空或安排其他存储资源。

再如，题目给出“主存地址空间为64MB，实际安装32MB RAM，按字节编址”，MAR应满足64MB地址空间，因此至少26位。

这里问的是整个地址空间需要多少位；若问“32MB存储区内部需要多少位偏移”，才是25位。

在3.3连接题中，较低地址位用于定位已安装存储区内部的位置，额外高位仍可能参与片选或译码器使能，决定这一存储区是否响应。

六、芯片地址位数与地址引脚数

对于\(4\text{K}\times8\)位、\(4\text{K}\times4\)位芯片，单元数都是：

\[ 4\text{K}=2^{12}. \]

所以两者都需要12位片内地址。在题目常见的非复用地址引脚连接方式下，都需要12根地址输入线；数据位宽则分别是8位和4位。

DRAM可能采用行、列地址分时复用。 例如，64K个单元需要16位逻辑地址，但可以把地址拆成8位行地址和8位列地址，分两次送入同一组8根地址引脚。题目问“地址位数”还是“地址引脚数”，要区分。

七、自测

自测1：读存储器时MAR和MDR分别放什么

CPU读取2000H单元，该单元存着A5H。MAR、MDR分别保存什么？

查看答案与解析

MAR保存地址2000H；读取完成后MDR保存数据A5H。RAM中的2000H单元是实际保存内容的位置。

自测2：容量相同，组织是否相同

\(8\text{K}\times8\)位与\(4\text{K}\times16\)位是否等价？

查看答案与解析

总容量都为8KB，但单元数和每单元位数不同。前者有8K个8位单元，后者有4K个16位单元。

自测3：32MB地址空间需要多少位

地址空间为32MB，分别按字节、按32位字编址，MAR至少多少位？

查看答案与解析

按字节编址：\(32\text{MB}/1\text{B}=2^{25}\)个地址，至少25位。

按32位字编址：\(32\text{MB}/4\text{B}=2^{23}\)个地址，至少23位。

自测4：安装容量能否直接决定MAR位数

某机按字节编址，主存地址空间64MB，安装16MB RAM。MAR至少多少位？16MB RAM内部偏移需要多少位？

查看答案与解析

MAR至少26位，满足整个64MB地址空间；16MB连续存储区内部的偏移需要24位。

八、做题前的检查

  • 问的是RAM容量、MAR位数，还是MDR中的数据？
  • 容量单位是bit还是B？\(1\text{B}=8\text{bit}\)。
  • 按字节编址还是按字编址？若按字，字长是多少？
  • 给出的是地址空间大小，还是实际安装容量？
  • 问芯片的逻辑地址位数，还是采用地址复用后的引脚数？
