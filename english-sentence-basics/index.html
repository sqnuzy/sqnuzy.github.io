简单句、句子成分与动词笔记（E₃—E₅）。

图片 1（E₃）：简单句

  1. 主语＋谓语
  2. 主语＋谓语＋宾语
  3. 主语＋谓语（系动词）＋表语
  4. 主语＋谓语＋间接宾语＋直接宾语
  5. 主语＋谓语＋宾语＋宾语补足语

主语是谓语的动作发出者。
宾语是谓语的动作接收者。

系动词主要分为以下六类

表示状态：be 动词（连接主语和表语，无意义，用于构成句子）。
表示感官：look、sound、taste、smell、feel（后面都只能加形容词）。
表示变化：grow、fall、turn、get、become。
表示保持：stand、keep、stay、remain。
表示表象：seem、appear。
表示结果：prove。

注意：根据意思判断是否为系动词。

双宾与宾补

双宾 → 之间没有关系。
宾补 → 补语是对前面宾语的补充说明。

在双宾或者宾语和宾语补之间加入系动词，语义顺畅则为宾补。

谓语

谓语 → 主动 / 被动＋时态＋{系动词、实义动词}

“主动 / 被动”下方标注：语态。

谓语只能是动词，动词只能是谓语。
一句话中找出不是谓语的动词，变为“不是动词”。

非谓语动词：

  • ing：主动
  • ed：被动
  • to do：表目的

图片 2（E₄）：英语括号法

主语

能作主语的成分：名词、代词、非谓语动词和从句。

非谓语动词作主语用单数。

being＋adj → 非谓语动词短语（处于某种状态）
be of＋n → adj

主语不能少。

无主语解决方案

  1. it 作主语（天气、温度、时间）
  2. There be 句型（“有”字）
  3. 被动语态
  4. 人称代词作主语

旁注：写作。

an increasing number of
↕
more and more

宾语

能作宾语的成分：名词、代词、非谓语动词和从句。

表语

能作表语的成分：名词、代词、非谓语动词、从句和形容词、介词短语。

动词

1. 实义动词（知道意思）

及物动词：后面直接加宾语，并且必须加宾语。
不及物动词：后面不能直接加宾语，必须加了介词才能加宾语。

2. 系动词

3. 情态动词

表明说话人态度的词汇。

表示对过去的推测：情态动词＋have done（一定做过某事）。

① must have done：一定做过某事。
② needn’t have done：本没有必要做，但是做了。
③ could have done：本能够做某事，但没有做。
④ should have done：本应该做某事，但没有做。
