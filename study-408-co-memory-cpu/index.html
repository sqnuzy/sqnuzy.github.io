一、本次优先掌握的考法

题目问什么 需要完成什么

这是本次学习的复习优先级，侧重能计算、能读图、能解释接线。题目要求画图时，应能画出标明上述信号的基本连接框图。

二、位扩展与字扩展：增加的是什么

把存储器看成一张表：行数是字数，每行宽度是每字位数。

对比 位扩展 字扩展
增加什么 每字位数，即位宽 存储字数，即单元数量
扩展后的组织 单元数相同，每单元更宽 单元更多，每单元位数相同
数据线 各片接数据总线的不同位 各组对应位共用数据总线
片选 同组各片同时选中 每次选择一个芯片组
地址 同组芯片接收相同片内地址 由高位区分组，低位定位组内单元

这些规则可对照清华大学出版社教材样章，第116～118页。

1. 只增加2位、2个字

从\(1024\times8\)位出发：

操作 扩展后 增加的总容量
每个字增加2位 \(1024\times10\)位 \(1024\times2=2048\)位
增加2个字 \(1026\times8\)位 \(2\times8=16\)位

一般地，\(M\times w\)位存储器增加2位后为\(M\times(w+2)\)位；增加2个字后为\((M+2)\times w\)位。

2. 再加2片相同芯片

原来只有1片\(1\text{K}\times8\)位芯片，再加2片，共3片：

方式 扩展后 增加量
全部用于位扩展 \(1\text{K}\times24\)位 每字增加16位
全部用于字扩展 \(3\text{K}\times8\)位 字数增加2K

两种方式的总容量都从1KB增加到3KB。每增加一片，增加的容量固定；“增加原容量的2倍”描述新增部分，“变为原容量的3倍”描述最终总量。

位扩展时，3片同时各提供8位，组成24位；字扩展时，每次选择一片，提供8位。

3. 增加芯片与增加地址位

  • 增加相同芯片：总容量按新增芯片的容量累加。
  • 增加1位可变地址：可表示的地址个数变为原来的2倍。
  • 增加2位可变地址：可表示的地址个数变为原来的4倍。

这里的地址个数是编码能力；要让新增地址有实际内容，还需要配置相应的存储器和译码。

三、芯片片数、每组片数和组数

目标为\(M\times W\)位存储器，现有芯片为\(m\times w\)位。规格可整除且按常规字位扩展组织时：

\[ \text{每组片数}=\frac{W}{w}, \qquad \text{组数}=\frac{M}{m}, \qquad \text{总片数}=\frac{M}{m}\times\frac{W}{w}. \]

先按位扩展组成一组，再按字扩展增加组数。 同组芯片提供同一个完整存储字的不同部分。

例如，用\(4\text{K}\times4\)位芯片组成\(16\text{K}\times8\)位存储器：

  • 每组2片，共同组成\(4\text{K}\times8\)位。
  • 一共4组，得到\(16\text{K}\times8\)位。
  • 共8片芯片，需要4路组片选信号。
  • 一次选中1组中的2片，各提供4位，共提供8位数据。

四、片选、字选、片选地址与CS

概念 含义
片选 确定本次由哪一片或哪一组芯片参与访问
片内寻址，也称字选 确定选中芯片或组内部的哪个单元
片选地址 CPU地址中用于判断访问哪片或哪组的地址位
片选信号CS 根据片选地址和访存条件生成的控制信号

理解关系：片选地址参与译码，生成片选信号；片内地址送入芯片，定位内部单元。 这是地址各部分的职责划分，不要求它们在时间上分两次到达。

位扩展时，同组多片使用相同的片内地址，也共用片选信号。某个地址对应的完整8位数据，可以由两片芯片分别保存高4位、低4位。

五、怎样划分地址线

1. 先从题目指定的最低位开始数

若芯片有\(2^n\)个单元，则需要\(n\)位片内地址。对于常见的非地址复用芯片：

  1. 从最低位起，取\(n\)位接芯片地址端。
  2. 若有\(2^k\)组，紧接着取\(k\)位作组选择，适用于连续、对齐的常规编址。
  3. 其余更高位参与存储区域的判断或译码器使能。

地址位编号的大小不决定高低位。通常A₀最低，但题目可以反过来规定。

2. 两种编号方向对照

CPU有16根地址线，使用\(4\text{K}\times4\)位芯片组成16KB存储器，按字节组织并连续编址：

作用 常规编号：A₀最低 反向编号：A₀最高、A₁₅最低
最低12位：片内地址 A₀～A₁₁ A₄～A₁₅
接着2位：选择4组 A₁₂、A₁₃ A₂、A₃
最高2位：区域判断 A₁₄、A₁₅ A₀、A₁

3. 做过的选择题：A₀为最高位

题意：地址总线A₀为高位，A₁₅为低位，用\(4\text{K}\times4\)位芯片组成16KB存储器，问产生片选信号的译码器的选择输入地址线。

选项 地址线
A A₂、A₃
B A₀、A₁
C A₁₂、A₁₃
D A₁₄、A₁₅

先自行完成，再展开答案。

查看答案与解析

选A。

16KB按字节组织为\(16\text{K}\times8\)位。每组2片\(4\text{K}\times4\)位芯片，共4组。

每组4K个单元，需要最低12位作片内地址。从A₁₅向高位数12根，是A₄～A₁₅；紧接着的两根为A₂、A₃，用来区分4组。

高位                                    低位
A₀、A₁ │ A₂、A₃ │ A₄…………A₁₅
区域判断│ 组选择  │ 片内地址
  2位  │   2位   │   12位

A₀、A₁仍可参与区域使能。因此，“译码器的两根选择输入”和“完整片选逻辑涉及的全部高位地址”要分开。

六、区域判断与全译码有什么用

1. CPU地址空间可以大于安装容量

16根地址线、按字节编址，对应64KB地址空间。实际只配置16KB存储器时，要决定这16KB放在哪个区域。

沿用反向编号，A₀、A₁为最高两位：

A₀A₁ 16KB区域
00 0000H～3FFFH
01 4000H～7FFFH
10 8000H～BFFFH
11 C000H～FFFFH

假设这块16KB存储器放在0000H～3FFFH，则只有CPU访存有效，并且A₀A₁为00时，允许它响应。具体应取哪种高位组合，由题目分配的地址范围决定。

2. 不判断高位会发生什么

若只用A₂、A₃选择组，用A₄～A₁₅选择内部单元，完全忽略最高两位：

0005H = 00 │ 00 │ 0000 0000 0101
4005H = 01 │ 00 │ 0000 0000 0101

两个地址的组号和片内地址相同，会访问同一个实际存储位置。这是地址重叠，也称地址镜像。

3. 译码方法与有效电平

方法 判断方式 需要理解的特点
线选法 某些高位地址线直接作片选 电路简单，地址空间利用和扩展受限制
全译码 片内地址之外的相关高位全部参与判断 每个存储单元对应唯一的系统地址
部分译码 部分高位不参与判断 不同系统地址可能指向同一个实际单元

高位参与判断，可以接译码器的选择输入，也可以通过门电路接使能端。全译码不要求所有高位都接在译码器的选择输入端。 可对照课程中的译码与CPU连接说明。

\(\overline{CS}\)表示低电平有效：0时选中，1时不选中。译码器自身的使能条件也必须成立，具体电平按题目给出的芯片引脚和真值表判断。

七、地址范围怎样计算

1. 已知首地址和地址个数

\[ \text{末地址}=\text{首地址}+\text{地址个数}-1. \]

按字节编址时，8KB存储区占\(8\text{K}=2000\text{H}\)个地址。若从2000H开始：

\[ \text{末地址}=2000\text{H}+2000\text{H}-1=3FFF\text{H}. \]

反过来：

\[ \text{地址个数}=\text{末地址}-\text{首地址}+1. \]

4000H～5FFFH共\(2000\text{H}=8\text{K}\)个地址；按字节编址，容量为8KB。按其他单位编址时，要再乘每个地址对应的容量。

2. 已知片选条件

固定片选条件对应的高位，低位片内地址从全0变化到全1，分别得到首地址和末地址。

例如，16位地址采用常规编号，每组4K个单元，高4位为0010：

最小地址：0010 │ 0000 0000 0000 = 2000H
最大地址：0010 │ 1111 1111 1111 = 2FFFH

3. 已知某地址，求所在组的范围

在连续、对齐编址条件下，保留高位片选部分：

  • 将片内地址全部清0，得到组首地址。
  • 将片内地址全部置1，得到组末地址。

例如，用\(2\text{K}\times4\)位芯片组成\(8\text{K}\times8\)位存储器，从0连续编址：

  • 每组2片，共4组，总共8片。
  • 每组2K个单元，占\(0800\text{H}\)个地址，片内地址11位。
  • 各组范围为0000H～07FFH、0800H～0FFFH、1000H～17FFH、1800H～1FFFH。
  • 地址0B1FH位于第二组，所在组的首地址为0800H，末地址为0FFFH。

位扩展的同组芯片使用同一段地址范围。 上例第二组的两片都对应0800H～0FFFH，各保存每个地址的数据的一部分。

八、完整连接例题：ROM与RAM

1. 题设与芯片选择

以下规格是为了讲解而设定的条件，实际题目按给定规格选片。

  • CPU有16根地址线，按常规编号A₁₅最高、A₀最低。
  • 数据总线8位，按字节编址。
  • 0000H～1FFFH为8KB ROM区，使用\(4\text{K}\times8\)位ROM。
  • 2000H～3FFFH为8KB RAM区，使用\(4\text{K}\times4\)位RAM。

ROM每片4KB，使用2片。RAM每片2KB，两片位扩展为一组4KB，需要2组，共4片RAM。

组号 组成 组内容量 高4位条件 系统地址范围
0 1片ROM 4KB 0000 0000H～0FFFH
1 1片ROM 4KB 0001 1000H～1FFFH
2 2片RAM 4KB 0010 2000H～2FFFH
3 2片RAM 4KB 0011 3000H～3FFFH

共6片芯片、4个组，使用4路组片选。

2. 地址与片选连接

  • 所有芯片均有4K个单元，CPU的A₀～A₁₁接各芯片的12个地址端。
  • A₁₂、A₁₃作2—4译码器的选择输入，产生4路组片选。
  • A₁₄、A₁₅参与使能判断，限定为00；还需结合CPU访存控制信号。
  • 同组两片RAM的CS端接同一路片选输出。

完整片选逻辑涉及4根高位地址线，译码器的组选择输入只有2根。

3. 数据线与读写控制连接

信号 连接方式
ROM的数据输出 每片8位分别接CPU的D₀～D₇
每组低位RAM片 4位数据接CPU的D₀～D₃
每组高位RAM片 4位数据接CPU的D₄～D₇
RAM读写控制 按题设连接读允许、写允许或读写控制端
ROM控制 正常运行时按只读方式连接；若有编程或写控制端，保持正常读模式

未被选中的芯片，其数据输出通常为高阻态，使不同组能够共用数据总线。

对\(\overline{OE}\)、\(\overline{WE}\)等低有效引脚，应按题目说明接入读、写信号。片选有效与读写条件必须共同满足，不能把“选中”直接理解成“正在写入”。

4. 访问2A35H，读写A5H

地址2A35H = 00 │ 10 │ 1010 0011 0101
            区域  组号      片内地址
  1. 最高两位00，允许本例16KB存储区响应。
  2. 组号10，选中第2组的两片RAM。
  3. 片内地址为A35H，两片均定位各自内部的A35H单元。
  4. 写入A5H，即二进制1010 0101：高位片写入1010，低位片写入0101。
  5. 读取同一地址时，两片各输出4位，拼回A5H。

地址2A35H回答“存在哪里”；数据A5H回答“存什么”。可与MAR、MDR的区别一起复习。

九、自测

自测1：增加2片还是增加2位地址

原来只有1片\(1\text{K}\times8\)位芯片，再加2片并全部作字扩展，结果是什么？若只是增加2位可变地址，可表示的地址个数怎样变化？

查看答案与解析

增加2片后，共3片，组织为\(3\text{K}\times8\)位。

增加2位可变地址，可表示的地址个数变为原来的4倍。地址编码能力和实际安装的芯片容量应分别计算。

自测2：片选路数看组数还是总片数

用\(4\text{K}\times4\)位芯片组成\(16\text{K}\times16\)位存储器，按字编址。共多少片、多少组、多少路组片选，一次选中多少片？

查看答案与解析

每组\(16/4=4\)片，共\(16\text{K}/4\text{K}=4\)组，总共16片。需要4路组片选，一次选中同组4片，共提供16位。

按字编址时共16K个字地址，需要14位地址；每组片内地址12位，组选择2位。

自测3：常规编号时哪些地址位选组

CPU有16根地址线，A₀最低。用\(4\text{K}\times4\)位芯片组成16KB存储器，安排在0000H～3FFFH，按字节编址。哪些位用于片内、组选择和区域判断？

查看答案与解析

A₀～A₁₁用于片内寻址；A₁₂、A₁₃选择4个芯片组；A₁₄、A₁₅用于区域判断，取值为00时允许这块存储区响应。

自测4：为什么必须判断区域

沿用上一题，如果完全忽略A₁₄、A₁₅，0005H与4005H会发生什么？

查看答案与解析

两个地址的低14位完全相同，会选中同一组的同一个内部单元，形成地址镜像。若要求完整、唯一的地址映射，高位也要参与片选判断。

自测5：按地址求范围

16位地址，采用连续、对齐编址，每组4K个单元。地址6B2CH所在组的首末地址是多少？

查看答案与解析

每组4K个单元，对应低12位片内地址。保留高4位6，将低12位清0得到6000H，置1得到6FFFH。

十、计算与画图检查顺序

  1. 明确bit、B和编址单位，先确定目标的单元数与位宽。
  2. 计算每组片数、组数和总片数。
  3. 确认地址位的高低方向，再划分片内地址与组选择位。
  4. 计算各组起止地址，检查连续编址中的容量与边界。
  5. 检查剩余高位和访存信号是否参与区域使能。
  6. 连接数据线、片选线和读写控制线，核对同组芯片是否同时工作。
