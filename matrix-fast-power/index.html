矩阵快速幂与常见半环模板

本文整理普通矩阵快速幂，以及图论和动态规划中常见的特殊矩阵乘法。

矩阵快速幂

[TOC]

1. 核心理解

矩阵快速幂通常用于：状态数较少，转移次数 \(k\) 很大，并且每一轮使用相同转移规则的问题。

若矩阵 \(A\) 表示进行一次转移，那么：

\[ (A^k)_{i,j} \]

通常表示从状态 \(i\) 出发，恰好进行 \(k\) 次转移后到达状态 \(j\) 的答案。

本文所有快速幂模板都要求 \(k \ge 0\)。如果没有“恰好 \(k\) 次转移”或其他大次数重复转移的限制，普通最短路、最长路或瓶颈路通常应使用对应的图论算法，不需要矩阵快速幂。

矩阵乘法可以统一理解为：

  • merge：经过中间状态 \(p\) 时，怎样拼接前后两段路径。
  • choose：有多个中间状态或多种路径时，怎样选择答案。

因此不需要死记多套模板，只需要判断两个问题：

  1. 两段路径拼起来，信息怎样合并？
  2. 多条路径都能到达终点，答案怎样选择？

所有模板的时间复杂度均为：

\[ O(n^3 \log k) \]

空间复杂度为：

\[ O(n^2) \]

2. 常见类型对照

类型 路径拼接 merge 多方案选择 choose 普通位置 单位矩阵对角线 常见用途
普通矩阵 x * y + 0 1 线性递推、方案计数
min-plus x + y min INF 0 恰好 \(k\) 步最短路、最小代价
max-plus x + y max -INF 0 恰好 \(k\) 步最大收益
min-max max(x, y) min INF -INF 最小化路径上的最大值
max-min min(x, y) max -INF INF 最大化路径上的最小值
布尔矩阵 x && y || false true 恰好 \(k\) 步可达性

单位矩阵对角线应当放 merge 运算的单位元：

  • 乘法的单位元是 1。
  • 加法的单位元是 0。
  • max 的单位元是 -INF。
  • min 的单位元是 INF。
  • 逻辑与的单位元是 true。

矩阵其他位置应当放 choose 运算的无效值：

  • 求和时放 0。
  • 取最小时放 INF。
  • 取最大时放 -INF。
  • 逻辑或时放 false。

9. 如何从题意判断类型

先观察两段路径拼接时发生什么：

题意 拼接方式
费用、距离、收益累加 +
关注整条路径的最大边权 max
关注整条路径的最小边权 min
只关心前后两段是否都可达 &&

再观察多条路径之间怎样选择：

题意 选择方式
统计所有方案 +
选择最优的小值 min
选择最优的大值 max
只要存在一条即可 ||

例如：

  • 恰好走 \(k\) 条边的最短路：拼接费用用 +，多条路径取 min，所以是 min-plus。
  • 恰好进行 \(k\) 次操作的最大收益：拼接收益用 +，多种方案取 max，所以是 max-plus。
  • 最小化路径上的最大开放时间：拼接路径用 max，多条路径取 min，所以是 min-max。
  • 最大化路径上的最小容量：拼接路径用 min，多条路径取 max，所以是 max-min。
