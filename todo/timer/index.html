        跨设备同步

        未开启

        用你自己的 GitHub Gist 当云盘：电脑、手机、不同浏览器用同一个 GitHub 账号，打开就能看到同一份记录。数据存在你私有的 Gist 里，不经过任何第三方服务器。

        1. 打开 github.com/settings/tokens（需要先登录）
        2. 页面里的权限列表很长，用 Ctrl+F 搜 gist，只勾这一项（描述是 Create gists），再点绿色 Generate token
        3. 复制生成的 ghp_… token，粘贴到下面，点「连接并同步」；另一台设备重复一次即可

        Token 只保存在这台设备的浏览器里；只给 gist 权限，随时可在 GitHub 撤销。

        已连接

        查看 Gist

        如果另一台设备上有记录、这里却是空的，先点「立即同步」；还不行就点「从其他 Gist 找回」，会合并你账号里所有带 study-time.json 的 Gist。

        数据

        示例数据会写入最近 7 天，可随时用「清空全部记录」删除，便于先看看图表效果。
